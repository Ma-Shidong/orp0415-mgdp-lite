# 项目进度汇报

## 一、已完成工作

1. 复现劭杰论文方法（LiDAR + 光流输入，PPO 端到端导航），跑通 Isaac Sim 训练全流程
2. 新增 **MGDP-lite 输入模式**：4 通道风险图（当前接近 / 去噪接近 / 高度走廊 / 动态 TTC），与 P2M 模式可随时切换，网络与旧 checkpoint 完全兼容
3. 完成训练/推理链路改造：支持多输入模式、checkpoint 续训、成功率课程（L0→L5）、模型轻量化
4. 搭建了与原论文一致的 **ROS 论文式批量评测平台**：map_generator + LiDAR raycast + 策略推理全链路自动化
5. 完成 200 trials 大规模对比实验（2 个 checkpoint × 5 个论文场景 × 20 seeds），输出成功率/速度/路径效率/安全距离全套指标
6. 新增训练监控脚本：done 分解监控、train/eval 差距告警

## 二、碰到的问题

1. GUI + flatcache 导致 Isaac 崩溃，需切换参数规避
2. 官方 P2M 权重为 3 通道，与当前 4 通道网络不匹配，无法直接加载
3. 训练成功率较高，但 ROS 评测成功率偏低，存在明显 sim-to-test gap
4. 最近续训（8000 iters，约 11 小时）成功率不升反降：开局约 15%，后期跌至 3~5%，93% 超时，课程全程卡在 L0——原因是续训后课程状态未保留、成功率未达 L1 门槛（35%），且 reward 被"刷分"（return 上升但到达率下降）
5. 当前无自动保存最优 checkpoint 机制

## 三、与 P2M 论文对比结果（20 seeds 实验）

在 5 个论文场景 × 20 seeds 共 200 次试验中，两个 checkpoint 均未超过 P2M 论文结果。较好的 `balanced` checkpoint 在 7 动 + 7 静场景成功率 65%（论文 95%），在"仅 25 个动态障碍"场景 40%，超过最强非 P2M 基线（25%）；但高密度混合场景（25 动 + 19 静）成功率 0%，仍是最弱项。

## 四、后续计划

1. 切换到 **MGDP-lite 输入模式**（仅换输入、不动网络和 reward），基于现有 checkpoint 续训并进行测试
2. 修复续训后课程状态未保留的问题，并调整 reward 防"刷分"（让成功率与 return 同步）
3. 实现 teacher-student 训练，利用 privileged 信息
4. 完善最优 checkpoint 保存
5. 扩大评测规模
